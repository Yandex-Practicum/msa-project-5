## Installation instructions

1. ensure you've [installed](https://www.python.org/) `Python`;
2. initialize a virtual environment: `python -m venv .venv`;
3. activate the virtual environment: `source .venv/bin/activate`;
4. upgrade pip: `pip install --upgrade pip`;
5. install dependencies: `pip install -r requirements.txt`.

## Using a client

Ensure steps of the `Installation instructions` section are completed.
The run: `python batch_client.py`.
