## Executive Summary

*Решение- использовать Apache Airflow как оркестратор для ETL пайплайнов. Apache Airflow имеет встроенные провайдеры для BigQuery, Redshift, Kafka, and Spark.*

---

## Context & Problem Statement

### Current State
Маркетинговый отдел планирует расширенно обрабатывать данные клиентов, объединяя их из разных источников, и формировать отчёты. 

В работе используются данные из разных источников: файловое хранилище CSV-файлов, содержащих статусы доставок пользователей, таблицы PostgreSQL с информацией о заказах, данные о платежах по заказам, расширенные данные о пользователях и данные из Kafka с цепочкой событий по модификации заказов.

Текущая система обработки не справляется с нагрузкой и запрашиваемым функционалом. Поэтому необходимо выбрать и обосновать технологическое решение для пакетной обработки данных.

### Business Requirements

- возможность гибко формировать пайплайн, 
- интегрировать его с внешними API, BigQuery, Redshift, Kafka и Spark
- поддерживать встроенный мониторинг и оповещения

### Technical Constraints
- Ожидаемый объём обрабатываемых данных за один запуск пайплайна — около 1 млн

---

## Decision

Решено использовать Apache Airflow:
 - Возможность построения сложных пайплайнов
 - Встроенная интеграция с API, BigQuery, Redshift, Kafka и Spark.
 - Есть мониторинг и алертинг из коробки

---

## Considered Alternatives

### Alternative 1: CronJobs

**Description:**  
Простой запуск заданий по расписанию

**Pros:**
- Быстрая настройка

**Cons:**
- Ручное управление
- Нет встроенного мониторинга

**Why rejected:**  
Не поддерживает сложные пайплайны

---

### Alternative 2: Spring Batch

**Description:**  
Оркестратор ETL в Java среде

**Pros:**
- Возможность создания сложных пайплайнов

**Cons:**
- Нет встроенной интеграции BQ, Kafka, Spark

**Why rejected:**  
Нет встроенной интеграции, нуден JVM-сервер

---

### Alternative 3: Все возможные облачные решения

**Description:**  
ETL оркестраторы как SaaS

**Pros:**
- Легкая настройка
- Нет необходимости поддерживать дорогую инфраструктуру

**Cons:**
- Не ясно будут ли доступны в будущем в связи с ситуацией в стране
