# Выбор технологического решения - Apache Airflow
* Для данной задачи оптимальный выбор - Apache Airflow. Airflow ориентирован на ETL/ELT и пакетную обработку данных.
* Airflow имеет готовые провайдеры и операторы для всех перечисленных источников в тз. Это позволяет ускорить разработку и внедрение решения. Также снижает ошибки при интеграции с внешними системами.
* Airflow поддерживает удобные механизмы ветвлений на основе DAG, управление потоками, триггеры, сенсоры. Это обеспечивает гибкое формирование пайплайна.
* Также из коробки у Airflow есть механизмы для ретраев, уведомлений, fallback-логику.

# Облачное развертывание
* Airflow можно развернуть в облаке:
    - Google Cloud Composer - управляемый airflow на GCP, интеграция с BigQuery, pub/sub
    - Amazon Managed Workflows for Apache Airflow - управляемый airflow на AWS, интеграция с Redshift, S3
    - Docker + k8s - горизонтальное масштабирование и возможность интеграции с Kafka, Spark
