В качестве решения был выбран **apache airflow**,
поскольку из-за своей архитектуры он дает возможность масштабироваться и подходит
для последовательных задач.

1) Выбранное решение хорошо интегрируется с BigQuery, Redshift, Kafka и Spark, из-за готовых модулей, дающих возможность
   легкой интеграции.
2) Airflow позволяет ветвить задачи, поддерживает условые операторы и event-trigger'ы (например из kafka).
3) Airflow дает возможность гибко настраивать fallback/retry/notification
4) Airflow можно легко развернуть в облаке (Amazon Managed Workflows for Apache Airflow/Google Cloud Composer) либо
   поднять вместе с kubernetes для удобной организации масштабирования через pod'ы.
