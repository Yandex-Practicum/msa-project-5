# План реализации

1. Согласовать состав полей прайс-листа и правила персональной цены для каждого клиента.
2. Подготовить параметризованный SQL-запрос с соединением `products`, `categories`, `clients` и `client_prices`; проверить число строк и отсутствие дубликатов для пары клиент–товар.
3. Упаковать небольшой экспортер в контейнер и настроить доступ к PostgreSQL через Kubernetes Secret.
4. Настроить CronJob на 06:00 в явном часовом поясе, запретить одновременные запуски и задать лимиты ресурсов.
5. Для каждого клиента записывать CSV во временный файл, затем атомарно публиковать его в доступном хранилище. Если нужен XLS, формировать его тем же запуском из результата запроса.
6. Проверить ручной запуск Job, состав и объём файлов, поведение при ошибке БД и отображение статуса в мониторинге Kubernetes.
7. После проверки включить расписание и предоставить клиентам путь доступа к готовым файлам.
