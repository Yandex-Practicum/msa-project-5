# Обоснование метрик (задание 5)

По теории спринта (мониторинг batch, Prometheus/Grafana):

| Метрика | Зачем |
|---------|--------|
| `jvm.memory.used` | Нагрузка на память при чанках |
| `process.cpu.usage` | Понимание CPU job |
| `spring.batch.*` (если доступны через Micrometer) | Статистика шагов |
| `http.server.requests` | Для задания 6 — вызов API |

Экспорт: **Spring Boot Actuator** + endpoint `/actuator/prometheus` (как в шаблоне).
