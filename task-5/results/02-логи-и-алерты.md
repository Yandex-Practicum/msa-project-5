# Логи и алерты

- **Логи:** JSON в stdout контейнера (logstash-logback-encoder), **Filebeat** забирает логи Docker (как в шаблоне), **Logstash** → **Elasticsearch** → **Kibana**.
- **Алерты:** правила в [`../initial/prometheus/alerts.yml`](../initial/prometheus/alerts.yml) (пример на доступность scrape или JVM — при необходимости скорректируйте под реальные метрики после первого запуска).

Grafana дашборд: [`../initial/grafana/provisioning/dashboards/batch-processing-dashboard.json`](../initial/grafana/provisioning/dashboards/batch-processing-dashboard.json).
