# Метрики ETL

| Метрика | Что показывает |
|---|---|
| `up{job="batch-app"}` | Доступность приложения для опроса Prometheus |
| `batch_job_runs_total{status="COMPLETED"}` | Количество успешных загрузок |
| `batch_job_runs_total{status="FAILED"}` | Количество завершившихся с ошибкой загрузок |
| `batch_job_duration_seconds` | Длительность загрузки; её можно сопоставлять с требованием 30 секунд для отчёта на 2 000 строк |

Доступность не равна успешной обработке: приложение может отвечать на запросы, пока ETL завершается ошибкой. Поэтому нужны и `up`, и счётчики по статусам. Длительность позволяет заметить замедление до нарушения требования к времени обработки.

Spring Batch публикует счётчики и длительность через Micrometer и Actuator. Prometheus Agent опрашивает `/actuator/prometheus` раз в 5 секунд и передаёт метрики серверу Prometheus. Grafana показывает доступность, успешные загрузки и среднюю длительность.
