# Логи и оповещения ETL

Приложение пишет JSON-логи в общий том. Filebeat читает файл, Logstash передаёт записи в Elasticsearch, Kibana позволяет искать их по полям. Файл выбран вместо чтения вывода контейнера, чтобы формат и путь логов не зависели от драйвера Docker. JSON сохраняет время, уровень и текст записи как отдельные поля.

Правила оценивает Prometheus: он уже получает метрики, поэтому для оповещений не нужен второй источник данных. Alertmanager отправляет письма; MailHog принимает их при локальной проверке.

| Правило | Условие | Причина |
|---|---|---|
| `BatchAppDown` | `up{job="batch-app"} == 0` в течение 30 секунд | При опросе раз в 5 секунд короткий сбой не вызовет письмо, а длительная недоступность будет замечена |
| `BatchJobFailed` | Рост счётчика `FAILED` за 5 минут | Ошибка обработки требует сообщения сразу после обнаружения; окно охватывает запуск между проверками правила |
